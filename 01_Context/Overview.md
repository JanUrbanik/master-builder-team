## How to use this folder

1. Read `AGENTS.md` first
2. Use `02_Agents/*` as individual system prompts (YAML frontmatter + body)
3. Append decisions to `03_Knowledge/KnowledgeBase.md`
4. Keep large source dumps in `04_Materials/raw/` (not default context)
5. Put approved plans in `06_Roadmaps/`
6. Put final deliverables in `07_Outputs/`
7. Machine routing topology: `01_Context/routing_manifest.yaml` (charter still wins per task)
