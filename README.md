# Master Builder Team

ADOPT A 16-agent Master Builder Team kit for **Grok Build**, with hardened routing, agent metadata, and marketplace plugins.

## Quick start

```bash
cd master-builder-team
export PATH="$HOME/.grok/bin:$PATH"
grok inspect
grok plugin list
grok mcp doctor
grok
```
